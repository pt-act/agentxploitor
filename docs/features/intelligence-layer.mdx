# The Intelligence Layer

AgentxploiTor is not a static tool that runs the same analysis every time. It is a living system that learns from experience, remembers what it has found, and autonomously improves its own capabilities. This is powered by two open-source, academically-grounded systems: **SimpleMem** and **Code-Voyager**.

## SimpleMem — Persistent Audit Memory

SimpleMem is an academic-grade memory architecture that gives AgentxploiTor persistent, queryable knowledge across sessions.

**What gets stored after every audit:**
- Target identity (contract address, URL, repo)
- All findings with severity, location, and confidence scores
- Tools and techniques used
- Contract version (bytecode hash) at time of audit
- Source code hash (when available)
- Reporter Farcaster FID and timestamp

**What this enables:**
- Every new audit of the same target begins with full historical context
- Semantic similarity search: "This contract matches patterns from 3 previous audits"
- Delta analysis: "These findings are NEW since your last audit. These were present before."
- Continuous monitoring: the system tracks what changed between contract versions

## Code-Voyager — Self-Evolving Skills

Code-Voyager is a university-research-grade system that mines audit transcripts and autonomously writes new skills — without any human intervention.

**How it works:**

```
Audit completes
    ↓
Code-Voyager Skill Factory mines the transcript:
  "I used this technique on this contract type"
  "This access control pattern appears in Base contracts repeatedly"
  "Proxy upgrade checks should run before reentrancy analysis"
    ↓
New SKILL files written autonomously
    ↓
Skills scored and refined across future audits
    ↓
Next similar audit: relevant skills retrieved and applied automatically
```

The agent writes its own improvement plan. We do not programme what it learns — it decides what is worth remembering from its own experience.

## The Compound Intelligence Effect

```
Audit 1:    Foundational security knowledge applied
Audit 100:  30+ Base-specific vulnerability patterns learned
Audit 500:  Contract families recognised, likely issues predicted

            built from real audits, not theory
```

Every user who requests an audit contributes to the intelligence of every future audit. Early users help train the system. The system gets better for everyone, permanently.

## What This Means for Continuous Monitoring

The intelligence layer is what transforms monitoring from "run the same scan again" to "pick up exactly where we left off":

```
Subscriber: Protocol X, monitoring enabled

First audit (Month 1):
  → Audited cold. Findings stored in SimpleMem.
  → Code-Voyager creates Skill: "Protocol X uses custom
    access control — check modifier inheritance first."
  → Brain updated: Protocol X profile stored.

Contract update detected (Month 3):
  → System loads full audit history for Protocol X
  → Loads Protocol X brain context and custom skills
  → Focuses analysis on what changed, not what was verified
  → Finds: 1 critical vulnerability in the NEW code specifically
  → Delta report: "This finding is NEW since your last audit."

Contract update detected (Month 6):
  → Two audits of history available
  → Custom skill refined twice from real findings
  → Audit faster and more precise than any fresh engagement
```

## Open Source Foundations

Both SimpleMem and Code-Voyager are open-source systems built on academic and university research. They are leveraged and integrated as the intelligence substrate for AgentxploiTor — not proprietary black boxes.

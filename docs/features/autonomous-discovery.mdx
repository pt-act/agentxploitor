# Autonomous Discovery

Agentxploitor scans targets and identifies security vulnerabilities autonomously, without requiring human prompting for each step.

## How It Works

```python
vulnerabilities = await agent.scan_target(
    url="https://defi-protocol.example",
    depth="deep"  # "quick" | "normal" | "deep"
)
```

The scanner:

1. **Reconnaissance** - Maps attack surface (endpoints, contracts, APIs)
2. **Vulnerability Detection** - Identifies common and complex vulnerabilities
3. **Risk Assessment** - Calculates CVSS scores and impact
4. **Prioritization** - Ranks findings by severity

## Supported Vulnerability Types

## Configuration

```python
await agent.scan_target(
    url="https://target.com",
    depth="deep",
    scan_types=["smart_contract", "web", "api"],
    timeout=300
)
```

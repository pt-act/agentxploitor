# Data Models

Core data structures used throughout Agentxploitor.

## Vulnerability

```python
from models import Vulnerability

vuln = Vulnerability(
    title="Unprotected Function",
    severity=Severity.CRITICAL,
    cvss_score=9.8,
    description="The withdraw function lacks access control",
    location="Vault.sol:142",
    cwe="CWE-862",
    remediation="Add require(msg.sender == owner)"
)
```

### Severity Levels

```python
from models import Severity

Severity.CRITICAL  # 9.0-10.0
Severity.HIGH      # 7.0-8.9
Severity.MEDIUM    # 4.0-6.9
Severity.LOW       # 0.1-3.9
Severity.INFO     # 0.0
```

## Exploit

```python
from models import Exploit

exploit = Exploit(
    technique="reentrancy",
    payload="...",
    target=vuln,
    safety_validated=True
)
```

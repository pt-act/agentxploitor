## 🎥 Recording Tips

### Before Recording
1. **Practice the demo**: Run it 2-3 times to ensure timing
2. **Test screen recorder**: Make sure it captures cleanly
3. **Close notifications**: Turn on Do Not Disturb
4. **Prepare voiceover**: Either record live or add after

### During Recording
1. **Keep terminal visible**: Full screen terminal
2. **Let the demo breathe**: Don't rush through output
3. **Highlight key moments**: Use mouse to point at important text
4. **Show the proof**: Actually open the screenshot file

### After Recording
1. **Review the video**: Watch for any issues
2. **Add text overlays** (optional): Reinforce key points
3. **Add voiceover** (if not live): Clear, professional audio
4. **Export**: MP4, H.264, 1920x1080, ~30fps

## Core Components

### Agent Core (`src/agentxploitor.py`)

Main agent that orchestrates the workflow:

- Initializes scanner and exploit generator
- Manages browser perception
- Coordinates the autonomous workflow
- Handles error recovery

### Security Modules (`src/`)

| Module | Purpose |
|--------|---------|
| `analyzers.py` | Vulnerability detection |
| `exploits.py` | Exploit generation |
| `models.py` | Data models |
| `ai/confidence.py` | Confidence scoring |
| `ai/explainability.py` | Finding explanations |

### Infrastructure (`src/infrastructure/`)

| Module | Purpose |
|--------|---------|
| `redis_queue.py` | Job queue |
| `database.py` | PostgreSQL connection |
| `health.py` | Health checks |
| `metrics.py` | Prometheus metrics |
| `tracing.py` | OpenTelemetry tracing |

## Data Flow

1. **Job Submission** → Redis queue
2. **Processing** → Worker picks up job
3. **Scanning** → Analyzer identifies vulnerabilities
4. **Exploitation** → Exploit generator creates proof
5. **Verification** → Browser automation captures proof
6. **Evaluation** → AI self-assesses quality
7. **Storage** → PostgreSQL persists results
8. **Submission** → Platform API receives findings

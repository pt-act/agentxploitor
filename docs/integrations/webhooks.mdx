# Webhooks

Agentxploitor can send real-time notifications to your systems via webhooks when events occur.

## Setup

Configure webhooks:

```python
from integrations.webhooks import WebhookConfig, WebhookEvents

webhook = WebhookConfig(
    url="https://your-server.com/webhook",
    events=[WebhookEvents.JOB_COMPLETED, WebhookEvents.FINDING_DISCOVERED],
    secret="your-webhook-secret",
    active=True
)
```

## Events

| Event | Description |
|-------|-------------|
| `JOB_CREATED` | New scan job started |
| `JOB_COMPLETED` | Scan job finished |
| `JOB_FAILED` | Scan job failed |
| `FINDING_DISCOVERED` | New vulnerability found |
| `FINDING_SUBMITTED` | Finding submitted to platform |

## Payload

```json
{
  "event": "FINDING_DISCOVERED",
  "timestamp": "2026-02-26T12:00:00Z",
  "data": {
    "job_id": "job-123",
    "target": "https://example.com",
    "finding": {
      "id": "vuln-456",
      "title": "Unprotected Function",
      "severity": "critical",
      "cvss_score": 9.8
    }
  }
}
```

## Signature Verification

Verify webhook authenticity:

```python
from integrations.webhooks import verify_signature

is_valid = verify_signature(
    payload=request.body,
    signature=request.headers["X-Agentxploitor-Signature"],
    secret="your-webhook-secret"
)

if not is_valid:
    raise PermissionError("Invalid webhook signature")
```

## Retry Logic

Failed deliveries are retried with exponential backoff:

```python
webhook = WebhookConfig(
    url="https://your-server.com/webhook",
    retry_config={
        "max_retries": 3,
        "base_delay": 60,
        "max_delay": 3600
    }
)
```

## Management API

```python
# Create webhook
webhook = await client.create_webhook(
    url="https://example.com/webhook",
    events=["job_completed", "finding_discovered"]
)

# List webhooks
webhooks = await client.list_webhooks()

# Test webhook
result = await client.test_webhook(webhook.id)

# Delete webhook
await client.delete_webhook(webhook.id)
```
